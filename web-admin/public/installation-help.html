Enable and connect

Open this plugin’s settings in Homebridge, then General → Web admin interface. Choose your saved deCONZ connections, set the HTTPS listener and browser address, and create your first web administrator. Save web settings applies this panel without changing garage door commissioning.

Web admin is optional. HomeKit and physical controls work with it off. Disabling it keeps your web accounts and collected history. Web accounts are separate from Homebridge accounts and alarm users.

deCONZ connections and keys

Add or update the shared deCONZ device connection in General in the Homebridge plugin settings. Its API key authenticates this application to deCONZ; it is different from your alarm PIN, Phoscon password and web login password. Existing keys are kept privately and are never displayed here.

After replacing a connection or key, save the Web admin settings again to verify and activate the current connection. A different gateway needs its own connection so existing history retains its original identity.

HTTPS and reverse proxies

The web address is the URL you open in your browser. The backend HTTPS address must match the Host and Origin sent by your proxy. The plugin creates a private self-signed backend certificate; your public certificate and its private key stay in nginx. Direct browser use requires trusting the backend certificate separately.

If the selected port is occupied by an existing web service, choose another port for testing or stop that service when you are ready to switch. This plugin does not stop another service for you.

Users, PINs and alarm access

Names, PINs and enabled status apply across a gateway. Access grants, keypad permissions, schedules and use allowances apply to the selected alarm. Keep an unrestricted owner for every managed alarm.

The Homebridge deCONZ alarm credential uses the official API for its existing Away, Home, Night and Disarm tile. New PIN updates need no restart or accessory-file edits. Homebridge saves the setting on its normal schedule. Its logs may contain the PIN; optional log clearing is offered before the update.

Interrupted changes

If a save loses its response, check the saved transaction and follow its recovery steps. Do not repeat the change automatically. A policy snapshot contains settings, not a backup of gateway credentials. An accepted command or elapsed timer does not establish physical door or bolt position.

Garage control

This interface uses the coordinator already running in this Homebridge plugin. Configure its virtual keypad under Garage doors → Controls. It shares the existing door and bolt coordination; no HTTP Webhooks plugin or separate controller service is required.
